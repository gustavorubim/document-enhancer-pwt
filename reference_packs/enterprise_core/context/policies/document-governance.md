# Document Governance Policy

**Reference ID:** POL-DOC-GOV-001
**Effective:** 2026-01-01
**Applicability:** Governed internal documents tagged `governed_document`

## Policy requirements

1. A governed document **MUST** identify an owner, status, version, effective date, next review date, and approving role.
2. A document **MUST** distinguish the stable document identity from its version. A rename does not create a new identity.
3. An approval record **MUST** name the approver role, decision date, decision status, and the artifact version approved.
4. A material change **MUST** create a new document version and preserve the prior version as superseded history.
5. A missing governance value **MUST** be shown as `TBD`, a blocking question, or an approved waiver; it MUST NOT be invented.

## Precedence note

This policy supplies the lifecycle minimum. The operational-documentation standard may add executable formatting and evidence detail, but it cannot remove these governance fields.
