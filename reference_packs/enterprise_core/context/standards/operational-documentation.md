# Operational Documentation Standard

**Reference ID:** STD-OPS-DOC-001
**Version:** 1.2
**Applicability:** Process, methodology, standard, and desktop-procedure documents

## Implementation requirements

1. Each executable action **MUST** have an actor, input, action, output, and completion condition.
2. Each decision **MUST** identify the evaluated condition, branch outcome, and next step.
3. Tables **SHOULD** be self-contained and include IDs, units, periods, and ownership where relevant.
4. A procedure **MUST** include a failure or escalation path when a step can fail or produce an exception.
5. A diagram **MUST NOT** be the only representation of an authoritative rule or sequence.

## Relationship to policy

These requirements implement the document-governance policy. If formatting convenience conflicts with a lifecycle requirement, the policy wins and the conflict is reported.
