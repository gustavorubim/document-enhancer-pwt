# Evaluation contracts

M8 evaluation evidence is generated by `scripts/run_evaluations.py` from the checked-in fictional
corpus. The JSON source of truth is `evals/reports/m8-offline.json`; the source-backed reader report
is `evals/reports/m8-evaluation.md`.

```bash
uv run python scripts/run_evaluations.py
uv run python scripts/run_evaluations.py --check
```

Every family, severity, and available format receives its own report. Graders cover raw-block
coverage/order, boundary precision/recall/F1, hierarchy, final schema validity, IDs/references,
dispositions, provenance, resolved blockers, unsupported claims, question/object/defect precision
and recall, stable chunks, SQLite/FTS/graph/vector completeness, embedding smoke rank, vector/FTS/
graph/fused retrieval, Recall@10/MRR/nDCG, graph paths, filters, follow-ups, groundedness, citation
precision/recall, unsupported claims, and abstention.

Offline evidence is a deterministic gold replay. It proves contracts and graders and makes no claim
about live Gemini quality, service latency, usage, billed price, or public-source generalization.
The report therefore records zero provider/public calls and labels live/public evidence
`opt_in_not_run`. `scripts/run_live_evaluations.py` is the separate credentialed route/lifecycle
probe; public downloads use the separate `public_download` path.

Section 20 thresholds are not weakened or silently skipped. The report includes observed, required,
status, and evidence kind for every release threshold, with per-family/channel/answer detail and a
failure/limitations section rather than only aggregate scores.
