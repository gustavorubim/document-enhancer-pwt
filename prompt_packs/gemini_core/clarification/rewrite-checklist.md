Create the machine-readable and reviewable rewrite checklist. Every item must point to a finding,
question/answer, steering item, reference rule, or audit requirement, name the target section or
object, state the intended action, verification method, acceptance criterion, and blocking state.
Do not permit a rewrite to proceed around an unresolved blocker without an explicit waiver.
